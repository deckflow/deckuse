# Edit an existing Word document

Use [verification-recovery](verification-recovery.md) for preservation and recovery. Prefer safe replaceText. Mixed-format replacements fail when formatting is ambiguous; narrow the edit rather than forcing firstRun unless that formatting change is intended. On older versions, stop mixed-format cross-run replacement. Do not bypass field, comment, revision, or hyperlink protection with direct run writes.

For native comments, tracked proposals, or accept/reject decisions, load [native review](review.md). Ordinary edits remain direct; use review proposals only when requested.
