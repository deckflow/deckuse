# Create a Word document

Create a DOCX workspace and enumerate styles before using a style ID. Plan heading hierarchy and tables. Use addParagraph, addTable, and insertBreak; geometry commands are unsupported. Read [preview-export](preview-export.md) for HTML/Chrome pagination and export, and [verification-recovery](verification-recovery.md) before delivery. Confirm heading order, page count, table splits, and selected pages. Style definitions and field updates remain outside the community write surface.
