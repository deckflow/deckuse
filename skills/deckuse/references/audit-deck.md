# Audit a presentation

Inspect package relationships, chart references, object geometry, and available render diagnostics. Distinguish structural errors from heuristic layout concerns. List image objects as unreviewed content, not confirmed statistical charts. Use delivery validation; a chart data verification refusal means unverified, not confirmed mismatch. Report native visual review separately.

Input: existing PPTX/workspace and review scope. Default read-only: preserve original, inventory slides/shapes and validate; render pages when layout review is requested. Read [verification-recovery](verification-recovery.md). Output findings with targets, evidence, severity and unverified areas. Repair only within user authorization, then enter edit-deck. Failed render or unsupported data is an unverified area, not proof of a defect.
