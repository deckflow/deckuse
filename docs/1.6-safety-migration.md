# Safe editing, data delivery and visual review

The wire protocol remains 2.0. These are optional capabilities plus fixes to previously unsafe editing behavior. Existing files remain inspectable and recoverable in structure mode.

## Word replacement

`replaceText` searches the original text once; replacement strings are literal even with regex. DOCX defaults to `formatPolicy: "safe"`: common unchanged prefixes and suffixes keep their original runs; the actual changed interval must have an unambiguous format. Complete run properties, character style, language and hyperlink boundaries matter. `firstRun` explicitly accepts first-run formatting inheritance and emits a warning. The CLI exposes `--format-policy safe|firstRun`; PPTX rejects this DOCX-only parameter.

Dry-runs report change offsets, paragraph/run targets, policy and formats. Ambiguous replacements fail with their formatting evidence. Fields, comments, revisions, controls and equations are protected conservatively, including document-spanning ranges and direct run writes/removals. Inline objects and hyperlink boundaries cannot be crossed. Zero-length regex matches are rejected. The original source, package, revision and operation log survive failed atomic batches.

## Chart data and isolation

Supported data updates synchronize the chart and embedded `.xlsx` in one workspace transaction. The supported surface is basic legacy charts (bar/column/line/pie and the community bar+line combination), finite numeric values and single-cell series names or referenced titles, fixed-size single-row/column A1 ranges, and constant cells. Quoted sheet names and shared strings are readable; string edits use inline strings so other shared-string consumers remain unchanged.

A shared chart is copied and rebound to the concrete target shape before changing it. A workbook shared by charts is likewise copied before data updates. Same-slide duplicated chart shapes, duplicated slides, and multiple updates in one batch are supported. All caches referencing affected cells inside the edited chart are refreshed, including category/title references. Conflicting writes are refused. Dry-run diagnostics list workbook/sheet/cell changes and isolated parts; undo restores all parts and relationships together.

Formula dependencies, external links, named/discontiguous/2-D ranges, range resizing, pivot data, macro/binary workbooks and unrecognized data extensions are refused. Known non-data Office extensions (leader-line display, invert-fill formatting and series identity) are preserved. Refusals never remove formulas, extensions or externalData to manufacture consistency. Styling and literal-data chart edits remain available.

`validate --profile structure` is the default and returns diagnostics without blocking unrelated safe edits. `--profile delivery` rejects inconsistent or unverifiable referenced chart data. Data states are `consistent`, `inconsistent`, `unverified`, `notApplicable`; `unverified` is not a confirmed mismatch. The report is recomputed from current package contents, including after reopen.

`export --profile delivery` checks the exact staged output before atomically replacing the destination. `--from-package` validates that snapshot, not source/. Failures preserve an existing destination, and temporary files are cleaned up.

## Preview and visual QA

Monitor defaults to 127.0.0.1; `--host` explicitly enables other interfaces. It shows target/rendered revision, the HTML backend, diagnostic severity, unreviewed image objects and native-review status. Failed conversions retain the prior frame with a prominent stale warning, including after reconnect. The full preview keeps its quality notice visible.

`validate --render` adds visual diagnostics. Bounds, malformed geometry and missing image references have object/page evidence; text overflow and content overlap are explicitly heuristic. Contained decorations are not universally treated as overlap failures. Group transforms, inherited placeholder layout and font substitution retain unverified status. Image objects are listed for semantic review, not automatically labelled statistical charts. HTML chart limitations remain warned until their rendering cases are verified.

The native writer now gives line series visible colored strokes, explicitly disables per-point color variation in bar/line plots, and allows default pie point colors. These fixes were found against the controlled PowerPoint baseline rather than by modifying correct OOXML to fit HTML output.

`render --engine libreoffice --page N` requires LibreOffice and Poppler (`pdfinfo`, `pdftoppm`). `DECKUSE_SOFFICE_PATH` selects the executable. Input bytes and SHA-256 are captured before conversion; an isolated profile/output directory and bounded process group are used, with timeout cleanup. The output reports page count and backend version; font/native status remains unverified. Configure the renderer's Fontconfig environment for Chinese fonts when necessary. Never infer Word-equivalent layout from LibreOffice success.

## Reproduce verification

After `pnpm build`:

- `node scripts/visual-baseline.mjs --native` builds eight controlled cases and attempts a native PDF export. Without `--native`, it does not launch Office.
- `node scripts/check-chart-workbook.mjs` creates an embedded-XLSX specimen, edits a copied slide, checks original-workbook preservation and verifies both caches/sources.
- `node scripts/native-office-check.mjs <specimen.pptx|docx> <output.pdf> [--roundtrip]` records bounded native evidence and source preservation; it closes only the specimen. `--roundtrip` adds a PowerPoint saved copy for reinspection.
- `node scripts/check-monitor-ui.mjs` uses headless Chrome to check ready → pending → stale-error UI behavior.
- `pnpm test:integration-writes:smoke` checks both formats. `pnpm check:no-commercial-leak` verifies edition boundaries.

Captured native specimens, page PNGs and environment evidence are in `test/fixtures/visual/native/`. See [verification evidence](verification-1.6-safety.md) for exact outcomes and limits. Scenario instructions are maintained as one common skill with seven references. Community master/theme/style/numbering definition boundaries remain unchanged.
